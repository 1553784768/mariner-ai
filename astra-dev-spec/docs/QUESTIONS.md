# QUESTIONS.md

遇到 AGENTS.md「不确定的事不自主决策」所列的事项时，在末尾追加一条，旧条目不要删。用户答复后，把状态改为 ANSWERED，填上答复，并同步修改相关文档。

## 模板

```
### Q-001 <一句话问题>
- 状态：OPEN
- 提出于：<任务 ID>，<日期>
- 背景：<哪份文档没写或有冲突，引用文件路径和原文>
- 可选项：
  - A. <选项> —— 影响：<…>
  - B. <选项> —— 影响：<…>
- 被阻塞的任务：<T-x.y>
- 当前处理：<跳过了什么，留了哪些 BLOCKED 标记或「待定」占位>
- 用户答复：
```
