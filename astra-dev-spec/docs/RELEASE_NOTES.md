# v0.1.0-preview.1

发布日期：2026-10-31。首个预览版本。

## 功能

- 本地 FastAPI / SQLite 后端与 Next.js 工作台。
- CSV 订单导入、确定性关税与利润计算、风险排序、决策与哈希审计。
- 政策采集、模型接入、分诊、抽取、规则校验、人工审核与日报。
- Approva 风格的收件箱、规则审核、流水线、日报和模型设置界面。
- Windows / Bash 启动脚本、离线夹具、单元测试与浏览器验收流程。

## 验证

开发验收记录：19 项 pytest、2 项 Playwright、Ruff、ESLint、TypeScript 和生产构建通过；Windows 独立安装副本启动通过。Linux 启动脚本仅做语法检查。

后台启动时发现的中文字体路径传递问题已修复，并以实际启动、HTTP 200、8 张订单卡和字体错误数为 0 验证。详见 [完整验收报告](ACCEPTANCE_REPORT_FOR_CLAUDE.md)。

可随 Git 交付的截图与日志保存在 [acceptance](acceptance/)。不包含运行数据库、API Key、环境配置、依赖或构建缓存；种子示例与离线测试夹具包含在源码中。
