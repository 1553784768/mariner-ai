# v0.2.0

发布日期：2026-10-31。

- 新增 AI 工作台、带引用的知识问答和数字守卫；订单数据须主动开启后才参与问答。
- 新增可检索、编辑和恢复的双语知识库；订单及影响单只读，知识编辑不改变计算。
- 新增 CSV/XLSX/PDF/图片导入任务、模型发送确认和可编辑预览，校验通过并人工确认后入库。
- 支持勾选具体建议采纳及填写补充说明，修复输入框快捷键误触，补齐成本与毛利率变化。
- 增加中英文切换、双语生成内容与审计、分类错误提示、格式检查及真实环境冒烟脚本。
- 修复原反馈 P1、P3–P10、P12–P14 的实现问题；P9 Linux 验证和 P2 真实联调尚未完成，P11 按规格暂缓。

开发验证：37 项 pytest、9 项 Windows Playwright、Ruff、前端 lint / TypeScript 和生产构建通过。详见 [v0.2 验收记录](ACCEPTANCE_V02.md) 和 [英文文案审阅清单](i18n-review.md)。
